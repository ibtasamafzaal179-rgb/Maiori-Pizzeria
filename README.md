# Maiori Pizzeria — Website Concept

A responsive five-page static website concept for Maiori Pizzeria, Peregian Springs, Sunshine Coast. Built with plain HTML, CSS and vanilla JavaScript — no framework or backend required.

## Pages
- `index.html` — home, positioning and awards
- `menu.html` — sample menu cards with category filters
- `story.html` — 48-hour dough and craft story
- `gallery.html` — responsive photo grid and Instagram review link
- `contact.html` — booking links and front-end enquiry message helper

## Files
- `css/style.css` — shared responsive styling, black/purple neon theme
- `js/main.js` — mobile navigation, reveal animation, menu filters and enquiry helper

## Preview locally
Open `index.html` in a browser. For a more realistic local preview, use VS Code Live Server.

## Before publishing
1. Replace temporary Unsplash images with Maiori-owned/approved photos.
2. Confirm exact award wording, current menu items and descriptions with the owner.
3. Add the current menu prices, street address, opening hours and contact details when verified.
4. Confirm the OpenTable booking URL and test it.
5. The enquiry form is a front-end demo. It does not send data to a database; it prepares an email draft and offers a copy-message option. Connect a real form service or backend only with the owner's approval.
6. Google Fonts and Unsplash images load from external websites, so an internet connection is needed for those assets.
